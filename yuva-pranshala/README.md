# Yuva Pranshala — Frontend (React + Vite)

Starter site features:

- Minimal homepage with responsive layout
- Navigation with smooth scrolling and mobile menu
- Restored hero slideshow with keyboard and swipe support
- Local SVG assets in `src/assets` used for the hero
- Accessibility improvements (skip link, keyboard controls, focus outlines)

## Run

cd yuva-pranshala
npm install
npm run dev

Open http://localhost:5173
